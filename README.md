Online Book Store

A simple Online Book Store website built using HTML, CSS, and JavaScript.

Features
📚 Browse books by genre
🔍 View book details
🛒 Add/remove books from cart
🔐 Login & Signup using LocalStorage
💳 Simple payment page
👨‍💼 Admin page
📦 Book data stored using JavaScript object literals
💾 LocalStorage for user and cart data
Technologies
HTML5
CSS3
JavaScript
LocalStorage
